# 演示前检查表

请在展示前 10 分钟按顺序检查，并用同一台电脑完成一次短流程。

## 电脑与程序

- [ ] Windows 默认扬声器或外接音箱可正常播放声音。
- [ ] 项目 `.venv` 可运行：`.\.venv\Scripts\python.exe --version`。
- [ ] `src/audio/native/stream_stretch.dll` 存在。
- [ ] 已关闭 Arduino 串口监视器、旧的采集器、`conduct_demo.py` 和其他可能占用 UDP 4210 的程序。
- [ ] 使用以下命令启动正式菜单：

```powershell
.\.venv\Scripts\python.exe -X utf8 src\desktop_app.py --encoder-port COM9
```

## 硬件

- [ ] 指挥棒已上电，MPU 固定牢靠。
- [ ] 指挥棒和电脑连接同一专用热点；避免公共 Wi-Fi 干扰。
- [ ] 编码器 USB 已连接，端口号与启动命令一致；旋转、短按、长按都有响应。
- [ ] 彩屏和灯圈独立上电、完成其负责板子的自检。

## 两条演示流程

- [ ] 动作作曲：进入“整体听感”，完成一次 3 秒倒计时和短录制，确认作品能试听。
- [ ] 动作作曲：如需展示起伏，使用“起伏映射”；如换使用者，先做个人校准。
- [ ] 音乐指挥：月光曲可由挥动开始、停手暂停，强弱可改变音量。
- [ ] 音乐指挥：卡农摇滚可随强度逐步出现键盘、贝斯、电吉他和鼓组。

## 发生异常时

- 编码器无响应：检查 COM 口与串口监视器占用。
- 指挥棒无响应：检查热点、供电、MPU 固定和 UDP 4210 是否被其他程序占用。
- 月光曲无法启动：检查 DLL、音频设备和 `requirements-tempo.txt` 依赖。
- 任意模式卡住：长按返回；必要时 `Ctrl+C` 退出后重新启动正式菜单。
