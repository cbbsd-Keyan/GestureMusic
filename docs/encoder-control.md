# 桌面编码器：电脑端连接

编码器固件以115200波特率经USB输出一行一个JSON事件。电脑端读取器不负责菜单；它只把已验证的旋转和按压转换为事件，供之后的作曲/指挥状态机使用。

先关闭Arduino IDE的串口监视器，再在项目根目录运行：

```powershell
.venv\Scripts\python.exe tools\encoder_monitor.py --port COM6
```

把`COM6`换成Arduino IDE显示的端口；当前这块板子是`COM9`。成功时会显示固件重启后的`ready`以及旋转、短按和长按事件。若端口被占用，先关闭串口监视器或其他读取该端口的程序；同一个串口不能被两个程序同时打开。

协议只有以下消息：

```json
{"type":"encoder","delta":1}
{"type":"encoder","delta":-1}
{"type":"encoder","press":"short"}
{"type":"encoder","press":"long"}
```

电脑端会忽略损坏、未知或附加字段的消息，避免随机串口文本被当作控制命令。

## 第一步：菜单实体交互

关闭串口监视器及`encoder_monitor.py`后运行：

```powershell
.venv\Scripts\python.exe src\desktop_app.py --encoder-port COM9
```

旋转选择“动作作曲 / 音乐指挥”，短按进入，长按返回。音乐指挥已经接入月光曲播放：选中曲目后短按进入待挥动，挥动开始播放，停手暂停；播放中短按暂停，暂停后短按重新进入待挥动，长按结束并返回。启动前关闭旧的`tempo_player.py --wand`、`conduct_demo.py`等占用UDP 4210的程序。

指挥曲库含根目录`moonlight.wav`和`assets/conductor/canon_rock.mid`。实时指挥不再变速：月光曲由指挥棒控制音量、启停；卡农摇滚版按原 MIDI 轨道同步播放键盘、贝斯、电吉他、鼓组，挥动能量会逐步加入声部。卡农优先使用 pygame，缺失时会自动使用 Windows 自带 MIDI 合成器，因此不依赖额外音乐库。编码器只负责选曲、暂停和结束。

## 动作作曲

作曲模式只使用规则作曲，不调用AI。进入后先旋转选择：`整体听感`（整段能量配器，默认）、`起伏映射`（现有能量时间线和逐小节动态配器）或`个人校准`。

个人校准依次录制最大自然挥动、舒缓挥动、自然发挥各5秒；每段短按后有3秒倒计时，录制自动结束。只有最大自然挥动的1秒RMS窗口95分位数用于新的个人锚值，另外两段只显示校准后的结果，不参与阈值计算。三段完成后短按才保存到`reports/live_demo/_sessions/<subject>/baseline.json`；确认保存前或取消时，旧基准不会改变。保存后下一次两种作曲模式都会立刻使用新基准。

选择整体听感或起伏映射后，短按开始3秒倒计时，随后录制；录制中短按结束，15秒自动结束，少于3秒或300个有效点会提示重录。录制结束后后台执行现有的画像、规则作曲、配器、存档和挥动曲线生成。

作品就绪后旋转选择“试听 / 保存 / 重录”。试听使用已有 MIDI 配器；长按会停止试听并关闭所有仍在发声的 MIDI 通道。存档自动写入`reports/live_demo/<时间戳>/`，其中包含输入、画像、乐谱和播放事件；动态模式额外包含能量时间线和动态配器报告。
