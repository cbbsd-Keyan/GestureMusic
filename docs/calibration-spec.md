# 个人校准说明

个人校准解决“不同人的挥动幅度不同”这一问题。它只影响后续动作作曲的强度映射，不影响月光曲和卡农指挥模式的播放速度，因为正式指挥模式已固定原速。

## 菜单流程

在“动作作曲 → 个人校准”中依次完成三段录制：

1. 最大自然挥动，5 秒。
2. 舒缓挥动，5 秒。
3. 自然发挥，5 秒。

每段短按后会有 3 秒倒计时。三段完成后，终端会显示结果；只有短按确认保存才会替换旧基准。长按会重新录制，取消不会破坏旧基准。

## 计算方式

系统以“最大自然挥动”中 1 秒角速度 RMS 窗口的 95 分位数作为个人锚值：

```text
归一化强度 = clamp(当前角速度 RMS / 个人锚值, 0, 1)
```

舒缓与自然发挥段只用于给用户查看校准效果，不参与锚值计算。

## 保存位置

当前桌面成品将校准保存到：

```text
reports/live_demo/_sessions/<subject>/baseline.json
```

默认用户编号是 `s00`，可通过桌面启动参数 `--subject` 改变。校准详情会与该次录制的 CSV 一起保留在同一目录。

## 使用建议

- 录制最大自然挥动时保持 MPU 固定、动作自然且足够有力。
- 更换指挥棒、明显改变固定方式或多人轮流使用时，应重新校准。
- 这不是“激烈/舒缓”的绝对判定，而是把个人动作范围换算到共同的配器尺度。
