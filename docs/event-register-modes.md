# 事件模式的音区对照实验

事件作曲现有三种选择：默认音区、相对俯仰角音区、摄像头位置音区。
`--posture` 与 `--vision` 互斥，二者都需要 `--events`。
姿态与视觉最终使用同一处音符计算，分别产生 -12、0、+12 半音偏移；
音符仍限制在原有音域内。事件检测、力度分组和伴奏生成共用。

## 运行

以下命令在项目根目录执行，要求已有可运行的项目 Python 环境。
如果 `.venv` 的解释器无法启动，需要先修复环境；本轮没有重建环境。

```powershell
# 普通事件：默认音区
.venv\Scripts\python.exe src\live_demo.py --events --device 1

# 姿态事件：原有俯仰角实验
.venv\Scripts\python.exe src\live_demo.py --events --posture --device 1

# 视觉依赖，只需安装一次
.venv\Scripts\python.exe -m pip install -r requirements-vision.txt

# 视觉事件：默认摄像头0，追踪亮点
.venv\Scripts\python.exe src\live_demo.py --events --vision --camera 0 --beacon bright --device 1
```

`--device` 应使用本机可用的 MIDI 输出设备编号。`--beacon green` 切换为
绿色亮点检测。仅普通与姿态模式不需要 OpenCV。

视觉模式先校准约 6 秒：让棒尖亮点在舒适范围内移动，随后按回车录制。
校准成功后保持同一摄像头后台取帧，录制开始时仅清空旧位置记录，不重新打开相机。
当前使用原有的画面上下、左右等权映射：画面右上为高音区、左下为低音区。
“上下优先”的权重，以及用户视角与摄像头镜像方向，尚未调整或现场验证。
俯仰角方案测量的是棒子倾斜程度，不是棒尖的空间高度。

## 回退与提示

- 摄像头打不开、校准失败、缺少依赖或读取失败：提示原因，使用默认音区。
- 相机打开与读取均在后台线程中；就绪等待和停止等待分别限时 2 秒。
  驱动永久阻塞时不会跨线程强制释放正在读取的设备，视觉回退为默认音区；
  资源由后台线程恢复后释放，或随进程退出回收。
- 单帧读取耗时超过 0.3 秒：丢弃该帧，避免把阻塞前的画面当作当前音区。
- 找不到挥动前后 0.3 秒内的视觉样本：本次挥动使用默认音区，并计为“未匹配”。
- 姿态模式挥动不足 6 次：提示并使用默认音区。
- 事件不足 3 次：回退规则作曲；同时传入 `--llm` 也不会改走模型。

## 存档与离线复测

视觉会话除 `input.csv`、`profile.json`、`score.json` 外，还保存 `vision.json`，
包含相对时间、音区样本、信标类型、摄像头编号、故障原因和 CSV 内容摘要。
新会话还保存 `sync` 对齐诊断：估计时间原点、首个设备时间戳、接收偏移跨度、
有效样本数、重复样本数和录制时长。旧版本的配套记录仍可复测。
默认与姿态模式不额外保存视觉文件。

```powershell
# 将目录名替换为实际生成的会话目录；不打开摄像头
.venv\Scripts\python.exe src\live_demo.py --events --vision --csv reports\live_demo\实际会话目录\input.csv --dry-run
```

`--csv --vision` 要求同目录有对应的 `vision.json`；版本、时间基准或 CSV
内容不匹配时会拒绝复测。普通旧 CSV 不包含视觉信息，不能用于视觉复测。
同一会话的 `input.csv` 也可不加 `--vision`，或改用 `--posture` 做对照。
`--dry-run` 跳过播放，但会生成新的存档与动作图。

录制前清空等待与校准期间积压的 UDP 包。对于每条有效动作数据，计算
“主机接收时间减去相对首条数据的设备时间”，用整段的最小值估计 CSV 起点
对应的主机时间，降低首包偶然延迟造成的整段偏移。视觉样本换算到这个原点后，
只保留 CSV 开始到结束之间的样本。

重复设备时间戳会跳过，非有限数值会过滤；设备时间戳倒退时终止录制并提示重录，
避免把乱序或重启后的数据拼接进同一会话。

该方法假设短会话内两个时钟速率近似一致，无法消除最小网络传输延迟、相机
曝光/缓冲延迟或校正时钟漂移。“接收偏移跨度”是诊断信息，不是实测同步精度。
尚未完成实物同步精度验收。

## 已做验证

回归使用现有 CSV、模拟视觉样本与硬件替身，覆盖三种模式、互斥参数、
视觉对音符的影响、故障回退、资源释放、时间转换与存档复测；另覆盖首包延迟、
区间过滤、重复/倒退时间戳、相机打开/读取阻塞、慢帧和校准中断。
未实际启动摄像头、连接开发板或验证 MIDI 出声。原有挥动峰值检测仍不区分
下挥和回程，本轮未修改该算法。
