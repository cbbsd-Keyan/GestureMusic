# 动作起伏驱动音乐配器

本轮完成“局部强度曲线 → 音乐时间映射 → 动态配器”。沿用现有事件音区控制、
视觉上下权重、镜像和音区图。大模型的分段旋律生成与局部BPM跟随尚未实现。

## 使用

`live_demo.py` 默认启用动态配器，适用于规则作曲、事件作曲和大模型返回的乐谱。
原有 `--events`、`--posture`、`--vision`、`--mirror` 参数继续使用。
`--static-energy` 切回整段能量配器，`--seed` 固定规则旋律，便于对照。
以下命令在项目根目录、可运行且装有项目依赖的Python环境中执行：

```powershell
python src/live_demo.py --csv data/batch_2026_09_w1/s00/free_001.csv --events --dry-run
python src/live_demo.py --csv data/batch_2026_09_w1/s00/free_001.csv --seed 42 --dry-run
python src/live_demo.py --csv data/batch_2026_09_w1/s00/free_001.csv --seed 42 --static-energy --dry-run
```

去掉 `--dry-run` 并指定本机 `--device` 后播放。该开关现在仍生成完整配器事件，
只跳过MIDI输出，因此离线检查和真正播放使用同一份事件数据。

## 强度与时间映射

- 能量曲线：1秒居中滑窗，每0.1秒计算角速度RMS和活跃比例。
  全段使用CSV同目录的个人 `baseline.json`；没有有效基准时统一使用
  `clip((rms-1)/5, 0, 1)`，不会对每个片段各自拉伸。
- 事件检测：局部中位数和偏差阈值，加固定有效幅度下限，减少强烈段淹没轻挥。
  仍是挥动合量的峰值检测，不区分下挥和回程。
- 事件乐谱：按乐谱原始BPM将格位换回动作时间；保留原来的事件位置和音区。
  小节末尾的音符缩短时值，不为容纳长音将起音强行挪到第12格。
- 规则／大模型乐谱：将完整动作按比例映射到音乐主体，自动前奏和尾声单独处理。
- 动态模式保持乐谱BPM恒定；能量只控制力度和织体，不再额外变速或升八度。
  每小节平均能量确定鼓、贝斯和伴奏档位，升降档使用不同阈值，至少保持一小节。
  音符力度随平滑能量变化，替代原有固定力度弧线和后半曲增强。
- 活跃比例低于0.05时暂停主体起音；持续音在检测到静止后的下一格以内结束。
  这是基于窗口统计的停顿，短于窗口的间隙可能被平滑，不等于逐样本立即静音。
- 事件模式补足的小节超出动作时长后不继续沿用最后的高强度。
- 非 `plain` 模式只要主体实际发声，就独立播放原有收束：最后和弦延长三拍、
  贝斯根音四拍，不受末尾停手门控。末尾静止或事件小节补齐时，收束紧接主体
  最后释放音，力度参考最后有效起音；全程静止仍保持无声。

`arrangement.build_arranged_events(..., dynamics=MotionDynamics(...))` 是新入口；
不传 `dynamics` 时保留原有整段配器路径，其他旧播放器不会自动改变行为。
原有画像与乐谱字段保持兼容，时间线以独立文件保存。

## 输出与显示

每次演示继续保存原始数据、画像、乐谱和动作图；新增：

- `energy_timeline.json`：局部强度、活跃比例、归一化方式、校准值及CSV摘要。
- `dynamics.json`：动作到音乐的映射、小节档位、前奏偏移和固定播放BPM。
- `playback.json`：实际调度的MIDI事件，含最终音符、力度及起止时间；静态模式也保存。

复用存档 `input.csv` 时优先读取配套能量时间线并校验摘要，保留原会话校准尺度。
不匹配或非法时间线会明确提示并回退整体配器。
动作图保留已有音区面板，另显示实际小节配器档位。虚线只是强度参考，
不再声称一跨线就换档。小节档位面板采用播放秒数，含前奏偏移。

## 验证与边界

固定同一份旋律，验证轻—强—轻、强—轻—强、渐强、静止、阈值抖动；
验证轻挥在强挥前后仍能检出、主体停顿、音符关闭、事件时间映射和旧配器兼容。
已有41段CSV覆盖规则与事件动态配器；保留姿态／视觉回归，并模拟大模型结果与失败回退。
未调用付费API、未连接硬件或实际试听。阈值和力度倍率仍需多人听感验收。

配器变强并不等于识别了心理情绪。本轮也没有根据强弱片段重写旋律主题或和声结构。
